# 벽돌깨기 게임

HTML Canvas와 JavaScript로 만든 기본 벽돌깨기 게임입니다. 별도 설치나 외부 라이브러리 없이 `block_crash.html`을 브라우저로 열면 실행됩니다.

## 출처

제공받은 다른 사람의 코드를 바탕으로 수정·확장했고 AI 코딩 도구의 도움을 사용했습니다. 원본은 [`reference/block_crash.original.html`](reference/block_crash.original.html)에 보존했습니다. 원본 작성자·공개 링크·라이선스는 현재 확인되지 않았으므로 알고 있는 출처가 있다면 추가하세요.

## 실행과 조작

1. `block_crash.html`을 더블 클릭해 브라우저로 엽니다.
2. 공 속도를 선택하고 게임 시작 버튼을 누릅니다.
3. 패들로 공을 받아 벽돌을 모두 깨세요.

| 입력 | 동작 |
| --- | --- |
| `←` / `→` | 패들 좌우 이동 |
| 캔버스에서 마우스 이동 | 마우스 위치로 패들 이동 |
| `Space` / 캔버스 클릭 | 대기 중 시작, 일시정지 중 계속하기, 종료 후 새 게임 |
| `P` / 일시정지 버튼 | 일시정지 또는 계속하기 |
| `R` / 다시 시작 버튼 | 점수·목숨·스테이지를 초기화하고 새 게임 시작 |

진행 중에는 `Space`나 캔버스를 눌러도 게임이 다시 시작되지 않습니다. 다른 창으로 이동하면 자동으로 일시정지하고 좌우 키 입력을 해제합니다.

버튼에 포커스가 있으면 `Space`는 그 버튼을 실행합니다. 캔버스를 클릭하면 경기장으로 포커스를 옮길 수 있습니다.

## 기능과 규칙

- 목숨은 3개로 시작합니다. 공을 놓치면 목숨 1개를 잃고 공·패들 위치를 초기화해 자동으로 계속합니다. 점수와 남은 벽돌은 유지합니다. 목숨이 0개가 되면 종료합니다.
- 벽돌은 한 번 맞으면 없어지고 1점을 얻습니다. 3개 스테이지의 벽돌을 모두 깨면 120점으로 승리합니다.
- 스테이지를 완료하면 다음 벽돌을 즉시 생성하고 공·패들 위치를 초기화합니다. 점수와 목숨은 이어집니다.
- 속도는 시작 전이나 게임 종료 후에 선택할 수 있습니다. 진행·일시정지 중에는 속도 선택이 비활성화됩니다.

| 스테이지 | 벽돌 배치 | 벽돌 수 |
| --- | --- | --- |
| 1 | 4행 × 8열 | 32개 |
| 2 | 5행 × 8열 | 40개 |
| 3 | 6행 × 8열 | 48개 |

공 속도는 느림 3, 보통 4, 빠름 5, 매우 빠름 6, 가장 빠름 7의 다섯 단계입니다. 값은 60Hz 업데이트 한 번의 이동값입니다. 게임 진행은 시간 정보를 이용해 1/60초 간격으로 갱신합니다.

| 아이템 | 효과 |
| --- | --- |
| E | 패들 너비를 100에서 150으로 8초 동안 확대 |
| L | 목숨 +1, 최대 5개 |

벽돌에서 떨어지는 아이템을 패들로 받으면 효과가 적용됩니다. 확대 시간은 게임 진행 중에만 줄어들고 일시정지 중에는 멈춥니다. 실점하거나 다음 스테이지로 넘어가면 확대 효과와 떨어지는 아이템이 초기화됩니다.

원본의 기본 이동·충돌·속도 선택·아이템을 유지하고 스테이지, 일시정지, 재시작, 마우스 조작을 추가했습니다. 코드를 쉽게 읽도록 최고 기록 저장, 콤보, 벽돌 내구도, 감속·터치 버튼·입자 효과는 제외했습니다.

## 코드 구성

`const`·`let`, 객체와 배열, 이중 `for`문, 함수와 `if`문, Canvas 그리기, DOM 이벤트를 사용합니다. 벽돌은 행·열 반복문으로 만들고 게임 루프에서 이동·충돌·그리기를 반복합니다.

| 함수 | 역할 |
| --- | --- |
| `initBricks` | 현재 스테이지의 벽돌 배열 만들기 |
| `startGame` | 새 게임 시작 또는 일시정지 해제 |
| `restartGame` | 진행 상태를 초기화하고 새 게임 시작 |
| `togglePause` | 일시정지 상태 바꾸기 |
| `nextStage` | 다음 스테이지 시작 또는 최종 승리 처리 |
| `movePaddle` | 좌우 키에 따라 패들 이동 |
| `moveBall` | 공 이동, 벽·패들 충돌, 목숨 감소 처리 |
| `checkBrickCollision` | 벽돌 충돌·점수·스테이지 이동 처리 |
| `moveItems` | 떨어지는 아이템 이동과 획득 처리 |
| `drawGame` | Canvas에 게임 화면 그리기 |
| `gameLoop` | 일정 시간마다 게임 갱신과 그리기 반복 |

## 확인할 내용

게임 로직 검사는 Node.js가 설치된 환경에서 `node scripts/verify-game.cjs`로 실행합니다. 현재 버전의 자동 검사 12개가 통과했습니다. 실제 화면과 브라우저 조작은 아래 항목으로 따로 확인합니다.

- [ ] 시작·화살표·마우스 이동, 벽·패들·벽돌 충돌
- [ ] 속도 5단계와 진행 중 속도 선택 제한
- [ ] 목숨 감소·종료, 스테이지 이동 후 점수·목숨 유지, 120점 승리
- [ ] E 확대·효과 만료, L 획득과 목숨 상한
- [ ] 일시정지·창 이동 시 자동 정지·계속하기·재시작

화면 배치와 실제 브라우저 조작은 위 항목으로 수동 확인합니다.
